# Nexus

The word *nexus* comes from latin meaning "a binding together".

This configuration aims to be exactly that: A binding between all aspects of work, creativity, and exploration, unified within emacs.

images here

## Description

Inspired by [N Λ N O](https://github.com/rougier/nano-emacs) and using [Doom](https://github.com/doomemacs/doomemacs) as a framework, Nexus aims to create an elegant and ergonomic experience; One that promotes a cohesive environment, rather than a collection of tools

>[!QUOTE]
> "It [Emacs] is a platform for interacting with a computer that is like mathematics is used for describing Physics."

Emacs does not need to simply be an editor. It can describe how one interacts with a machine.

It cen become the **Nexus** between the user and the system itself.

# Prerequisites

Nexus depends on Doom and assumes it is already installed. For information on *its* dependencies visit the [repo](https://github.com/doomemacs/doomemacs), otherwise you can install it via the following command

``` sh
git clone --depth 1 https://github.com/doomemacs/doomemacs ~/.config/emacs
~/.config/emacs/bin/doom install
```

It is also assumed that you have base level knowledge of how to use and configure Doom.

Some other package dependencies are as follows:

- [eza](https://github.com/eza-community/eza) (for divish previews)
- [mu](https://github.com/djcb/mu.git) (for mu4e)
